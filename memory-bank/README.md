# Memory Bank

Contexto do projeto para retomar o trabalho sem precisar redescobrir tudo.
Leia nesta ordem:

1. **projectbrief.md** — o que é e qual o escopo.
2. **productContext.md** — por que existe e as decisões de experiência.
3. **systemPatterns.md** — arquitetura e os padrões do código.
4. **techContext.md** — stack, estrutura de pastas e armadilhas do ambiente.
5. **designSystem.md** — paletas, tokens e regras visuais.
6. **activeContext.md** — em que ponto o trabalho está agora.
7. **progress.md** — o que funciona, o que falta, o que não reverter.

## Manutenção
- `activeContext.md` e `progress.md` mudam a cada rodada de trabalho.
- `systemPatterns.md`, `techContext.md` e `designSystem.md` só mudam quando uma decisão
  estrutural muda.
- Datas sempre absolutas (`2026-09-06`), nunca "ontem" ou "semana passada".
